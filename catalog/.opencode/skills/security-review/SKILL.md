# Security review

Review evidence without reading secret values. Check authentication and authorization at every endpoint, object ownership, input validation, SQL/path injection, CORS, file storage, logs, default credentials, secret injection, and environment separation. Report severity, evidence, impact, remediation, and regression tests. This skill is read-only.

Official references: https://owasp.org/www-project-application-security-verification-standard/ and https://cheatsheetseries.owasp.org/
